# Minimal dependency set to RUN THE DASHBOARD on the bundled demo dataset.
#
# The dashboard itself never imports ib_async or the FinViz client — those are
# only needed to COLLECT new data. So a reviewer who just wants to open the app
# and look at the chart can install this shorter list instead of the full
# requirements.txt (no broker library, no scraping stack).
#
#   pip install -r requirements-demo.txt
#   python -m scripts.demo_dataset load
#   python -m app
#
# Tested on Python 3.12.4.
